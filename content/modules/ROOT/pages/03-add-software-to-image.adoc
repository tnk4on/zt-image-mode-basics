= ソフトウェアの追加

ソフトウェアは Containerfile で管理されます。パッケージの変更や追加を行うには、ビルド前にここで定義する必要があります。すでにビルドされたイメージを新しいバージョンに更新する場合は、再ビルドするだけです。

`Build host` ターミナルに切り替えて、`Containerfile` を編集用に開きます。

`+dnf install+` 行の末尾にパッケージ `+vim+` を追加します。

[source,bash,run,subs=attributes+]
----
vi Containerfile
----

[source,dockerfile,nocopy]
----
FROM registry.redhat.io/rhel10/rhel-bootc:10.1

ADD etc /etc

RUN dnf install -y httpd vim # <1>
RUN systemctl enable httpd
----
<1> この `RUN` 行に `vim` を追加するだけで、追加パッケージのインストールは完了です

== podman を使用したイメージの更新

Containerfile に変更を加えたら、`+podman build+` コマンドを再実行して更新されたイメージを取得します。

[source,bash,run,subs=attributes+]
----
podman build -t builder-{guid}.{domain}/test-bootc .
----

ソフトウェアをインストールする `+RUN+` コマンドは、設定ファイルをインストールする `+ADD+` コマンドの後にあるため、`+podman+` は再ビルドせずにキャッシュされたレイヤーを使用していることに注目してください。レイヤーのキャッシュと順序は、標準的なオペレーティングビルドを設計・更新する際の強力なツールとなります。

== レジストリへのイメージのプッシュ

更新されたイメージがビルドされたら、レジストリにプッシュします。ここでも、変更されたレイヤーのみがレジストリに追加されることに注目してください。

[source,bash,run,subs=attributes+]
----
podman push builder-{guid}.{domain}/test-bootc
----
